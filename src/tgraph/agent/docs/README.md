# TGraph Agent Docs

Short references for TRACE agents that author, validate, and repair TGraph stage artifacts.

- `artifact-files.md`: outer artifact shape and support-file locations.
- `fact-kinds.md`: allowed logical and physical fact kinds.
- `checkpoint-files.md`: checkpoint function contract and repair-friendly issues.
- `mutation-files.md`: transactional graph mutation file contract.
- `naming.md`: node, port, link, and link-key naming rules.
- `catalogs.md`: static image/flavor knowledge policy for physical checks.

Keep these docs queryable and compact. Prompts should reference these files instead of repeating long API details.
